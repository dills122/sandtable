## Recommendation

Split009 into **009A inherited assessment and identity values**, then **009B exhaustive positive
profile certification**. Keep parent009 open after009A. This is an execution split, not a new
contract, profile or domain. Each implementation slice gets its own developer/three-review gate.
Start009A only after H4 acceptance. Do not make actual positive assault, final opportunity admission,
public disclosure or current Snapshot12 gameplay arms prerequisites for this first slice.

Five proposed primary paths for009A:

1. `src/Cna.Core/Campaigns/CampaignCombatIdentityModels.cs` — immutable Participant and
   CandidateAssessment/AdmissionBoundary values matching existing ordered contracts. Reuse existing
   UnitKey/ComponentKey/CycleAuthority; never mint alternative persistent unit identity.
2. `src/Cna.Core/Campaigns/CampaignCombatIdentityCodec.cs` — canonical writers/readers for those
   existing value shapes. Candidate and opportunity-v2 preimage follow in009B; no unused final-round
   type introduced in009A. No Command/Event/Control/round/slot transitions.
3. `src/Cna.Core/Campaigns/CampaignCombatCertification.cs` — mandatory retained creation + full
   ordered history replay, require actual typed completed G2 cut, derive the frozen inherited
   assessment and exact AdmissionBoundary. Keep this entry point restricted to accepted CP12/14
   histories; unsupported history rejects, never returns a guessed empty candidate collection.
4. `tests/Cna.Core.Tests/Campaigns/CombatIdentityTests.cs` — actual empty G2 witnesses, identity
   continuity/non-aliasing, exact value/identity vectors and rejection tests.
5. `tests/Cna.Core.Tests/Cna.Core.Tests.csproj` — link existing inherited-selection, selection and
   sealed-round-v2 fixtures as needed. No new fixture generator or edits to frozen artifacts.

Existing `CombatMovementHistoryReplayTests.SnapshotHistories()` supplies six/seven-move terminal
histories for both owners without another trace generator or sixth path. Existing precycle/Reaction
history enumerators supply invalid predecessor and provenance tests. Tests may consume existing
fixture JSON to select expected values, but production admission must never consume fixture labels,
caller assessment or expected-state JSON. Serialization can embed existing typed G2 writer bytes.

009A binds Participants from trusted validated World/Content independently of eligibility; assessor
uses those exact bindings to derive acting/defending identity and location fields. These values are
part of actual assessment execution, not unused hypothetical models. Binding grants no permission
to attack. Candidate serialization and exact opportunity preimage tests follow in009B.
Expose no positive candidate-offer API until009B certification passes. Do not use a stub that treats
unsupported positive inputs as empty or silently normalize inherited state to C3a initial state.

009B proposed primary paths: new `CampaignCombatProfileCertification.cs`, plus bounded changes to
`CampaignCombatCertification.cs`, `CampaignCombatIdentityModels.cs`,
`CampaignCombatIdentityCodec.cs` and `CombatIdentityTests.cs` (five). Reassess exact
ownership before dispatch; no whole lifecycle or snapshot implementation belongs in these files.
A single five-file009 implementation is mechanically possible but mixes two trust boundaries,
exhaustive geometry/arithmetic proof and multiple canonical value families. Split keeps first
result reviewable and makes absence of live positive certification explicit.

  current hex occupant.009 tests binding refusal/original provenance;016 owns actual relation changes.

  Hash grammar validation cannot authenticate caller baseHash/decline receipt. Only010 replayed
  selection+decline and011 authenticated Base2 may invoke it for actual admission. This resolves
 009→010→011 dependency without executing later tasks early or accepting caller JSON as authority.

  Full equal-visible-artifact assertion remains020. Ambiguous profiles reject before opportunity
  offer; suppressing duplicates or sorting hidden IDs does not satisfy trusted certification.
