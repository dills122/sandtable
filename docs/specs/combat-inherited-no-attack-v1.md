## Objective and authority

Admit only the exact four creation-rooted histories accepted by the predecessor: either acting side,
six or seven ordinary moves, CP12/14, Cohesion -2/-4, normal Weather, nonadjacent rear/supply
infantry, and a closed empty selection. Preserve the predecessor `Control` byte-for-byte as the
immutable `selection` member of a new traversal `Control`. The predecessor's two receipts, moved
World, RNG, authority identity, Weather/Breakdown proofs, and sequence position remain authoritative.

System alone may submit `complete-step`. Each command binds contract version2, predecessor segment,
exact current position, current state version, and the accepted selection-closure receipt. A caller
cannot supply successor position, proof kind, previous receipt, or event identity. Rejected input
changes no state. An exact accepted input retry returns its original receipt and event bytes without
advancing again.

Fresh command authority enters through the history-rooted `apply` boundary. It reconstructs current
3e Control from full accepted creation-rooted history plus ordered 3d/3e events before invoking the
pure internal transition. An optional cached Control is advisory only and must be canonical and
byte-identical to replay; forged nonzero prefix or traversal-receipt ledger rejects before command
execution. Duplicate commands return the original accepted event bytes found in the supplied 3e
event list, never newly generated bytes or cache-derived authority.

## Exact transition and receipt rules

The only accepted path is:

1. Position Determination -> Barrage
2. Barrage -> Retreat Before Assault
3. Retreat Before Assault -> Force Assignment
4. Force Assignment -> Anti-Armor
5. Anti-Armor -> Close Assault
6. Close Assault -> same-slot Reserve Release

Every accepted event is `combat-step-completed`2 with `proofKind=no-attack` and
`dispositionReceiptId` equal to the immutable 3d `selectionReceiptId`. First event's
`previousStepReceiptId` is 3d's segment-opening receipt; each later event names the immediately
preceding step receipt. Receipt ID uses the packet's domain-separated canonical unsigned event.
Prefix advancement uses exact canonical event bytes. State version advances once per accepted event.

Outer `Control.position` is the catalog Position reached by latest completion. `stepIndex` counts
accepted completions from zero through six. `closed=true` only after Close Assault reaches Reserve
Release. Nested 3d `selection.segmentClosed` remains false because frozen predecessor bytes cannot be
rewritten; outer closure is the authoritative 3e completion fact. Reaching Reserve Release releases
nothing, resets no ledger, closes no Operation Stage or cycle, and emits no extra segment-completed
event.

No completion changes World, CP, BP, Cohesion, TOE, Ammo, attacked history, target use, Weather,
Breakdown history, RNG, candidate assessment, or selection outcome. Positive candidates, selected or
cancelled paths, gun/Barrage/RBA/assignment work, attack preparation/commit/result/settlement, and
release actions are unsupported.

## Canonical bytes and replay

All objects are exact-key, recursively typed canonical JSON UTF-8. Objects use schema order; arrays
retain order; integers cannot be booleans or floats; unknown, duplicate, escaped, reordered, padded,
BOM-prefixed, malformed, oversized, or over-deep input fails closed. Limits are 1,048,576 bytes,
depth32, six events, six traversal receipts, and signed 64-bit state versions.

Restore independently rebuilds the full creation-rooted history through 3d, compares exact nested
selection bytes/hash, and applies each accepted 3e event from its authenticated input. Missing,
duplicated, reordered, cross-history, cross-side, stale, wrong-position, wrong-disposition, forged
receipt/effect, and post-close events reject. Every prefix cut reconstructs identical next capability
and Control bytes.

Diagnostics are stable `CMB-CIN-001` through `CMB-CIN-008`: size/depth/shape, scalar, command/effect,
identity/receipt, authority/predecessor, state/order, capacity/scope, and noncanonical bytes.
