# Actual moved-repeat Breakdown completion v1 (provisional)

This private reference contract extends the authentic R02 paid/armed moved-repeat Movement completion into one trusted System Breakdown completion. [R02](combat-actual-moved-repeat-movement-completion-v1.md) remains the only predecessor authority. The distinct [B02 contract](combat-actual-repeated-breakdown-completion-v1.md) supplies a semantic precedent, not a substitute ancestor. The [schema](combat-actual-moved-repeat-breakdown-completion-v1.schema.json), [verifier](verify-combat-actual-moved-repeat-breakdown-completion-v1.py), and [focused checks](test_combat_actual_moved_repeat_breakdown_completion_v1.py) are provisional and do not certify native, public, Runner, full72 or release-candidate behavior.

## Authority and admission

The Source carries exact R02 source bytes and zero or one own event. Callers supply the original CreationRequest, all ten independent R02 ledgers and the eleventh Breakdown ledger. The verifier reacquires the pinned predecessor schema/oracle and their 104 external material files, then fully replays the R02 source before interpreting an own event or Control/Proof claim. Input collections and current command are owned before the first physical callback. Missing or changed material rejects rather than becoming an empty ledger.

Only a terminal R02 state with active turn 1, operation stage 1, first-acting-side ordinal 2, `phase=breakdown`, `closed=true`, idle flow and null interrupt context is supported. It must retain the ordinal-one proof and prior-cycle closure, and its ordinal-two MovementEndProof must bind the actual last lifecycle receipt. The full Breakdown position must match the canonical catalogue. Zero-move history has one R02 lifecycle event; positive history has stop, empty System resolution and completion. The intended profile covers all 300 R02 terminal rows across paid/armed, both sides and all admitted move cuts; all 300 passed the local semantic gate. Nonterminal, foreign-cycle, cohort and alternate-lineage sources reject explicitly.

## One-event transition

The only command is `complete-breakdown-segment` from actor `system`. Its action identity binds version/kind/operation stage; its capability binds the actual Base, cycle, version, complete position and R02 completion receipt. Actor, closed input shape and context checks precede exact accepted retry lookup. A byte-identical prior command returns the original receipt and source without another event even when fresh admission is disabled. New commands require advertised handler/capacity support and one signed version slot.

The event derives its sources from the actual Breakdown position, binds the actual R02 source, cycle, version, prefix and command, and advances to the immediately adjacent canonical Combat Position Determination. The own Control carries an immutable canonical predecessor Control string plus own position, prefix, version, phase and receipt. It moves `phase` to `combat`, closes only the own fragment and leaves active ordinal two open. World, CP/DP, ammunition, TOE, members, histories, RNG, actual movement, both MovementEndProofs, prior closure and progress are retained in the authenticated predecessor Control. The transition consumes no RNG and performs no check, loss, cost, new repeat or public action.

## Closed encoding and provisional limits

The schema fixes exact property order, nested types, one own event/receipt, no duplicate keys, ASCII canonical JSON and error families CMB-MRB-001 framing, 002 numeric, 003 unsupported, 004 binding, 005 action/capability, 006 replay/order, 007 capacity/admission, 008 canonical bytes and 009 physical acquisition. Own raw bounds are Source 256 MiB, parent carrier 128 MiB, Control 2 MiB, Proof 4 MiB, Event 32 KiB, Input 4 KiB and depth 42. These are provisional, not a capacity certificate. R02's stated valid-state Source upper bound is 128,857,600 bytes; doubling carrier escaping plus one own event and framing yields a candidate child Source bound of 257,781,248 bytes, below the 256 MiB raw cap. The provisional structural model places Control at 1,703,936 bytes, Proof at 1,835,008, Event at 16,384, Input at 2,048 and the own ledger at 2,050, below their current caps. The complete runtime acquisition set matched all 108 declared paths, and 540 missing/changed/unreadable/null/drift faults rejected. Independent review and near-limit native allocation and latency evidence are still required before `closureFrozen` can be set.

All 300 genuine terminal cases passed the local semantic gate across 18 sequential groups in 711.221 seconds; this is not a hosted parallel-CI timing claim.
