# P01 private local host foundation v1

**Status:** bounded, unissuable host foundation for owner-approved Choice L ([decision packet](../design/p01-a2-local-owner-authority-decision-v1.md), merged #299). Choice L approves the local grant-custody trust model and SQLite design direction, not exact A2 opening/input schemas or admission. This store holds no P01 owner opening, action, event, receipt, public alias or admitted campaign. No route or dependency-injection registration uses it. The accepted owner codec remains [P01 owner decision v1](combat-p01-owner-decision-proposal-v1.md); the proposed read/submit design is [A2 owner path](../design/p01-private-owner-path-proposal-v1.md), merged #297. The P01 acceptance freeze and public/native admission gates remain open.

## Trust boundary

The proof owner is the holder of a host-issued, single-use campaign/side grant, **not** a verified person. The operator secret must be provisioned outside browser bootstrap and never returned by a route. This package does not import a CreationRequest or trust a caller's checkpoint hash. Its campaign-binding and journal probes are test-only storage primitives until a separately reviewed Core A1 checkpoint adapter authenticates their inputs. A future A2 implementation cannot call an owner opening until Core derives approved public refs, own participant and visible hex from one readback-verified cut, and the exact A2 schemas and acceptance amendment are separately approved.

## Closed foundation schema

The SQLite database has `application_id = 0x50303146` (`P01F`), `user_version = 1`, `journal_mode = WAL`, `synchronous = FULL`, foreign keys enabled, and a 5-second busy timeout. Unknown database version, application ID, missing required table/column layout or failed integrity check is unavailable; there is no automatic migration. Single-host local file, WAL and SHM form one authority unit. File directory must be private to the host user. Recovery cannot copy only the database file while writes continue.

| Table | Key and exact columns | Meaning |
| --- | --- | --- |
| `operator_capability` | `singleton INTEGER PRIMARY KEY CHECK(singleton=1)`, `secret_digest BLOB NOT NULL` | One provisioned host-only operator capability. Browser bootstrap is unrelated. |
| `campaigns` | `campaign_id TEXT PRIMARY KEY`, `checkpoint_hash TEXT NOT NULL`, `head_sequence INTEGER NOT NULL`, `head_hash TEXT NOT NULL`, `activation_fence INTEGER NOT NULL`, `activation_digest BLOB NOT NULL` | One unissuable private binding. Initial sequence 0 is a storage binding, not a second R03 event. `checkpoint_hash` is an opaque authenticated-A1 input slot, never a supplier-selected authority here. The activation digest binds a random lease secret to the current fence. |
| `seats` | `(campaign_id, side)` primary key; `authority_id TEXT UNIQUE`, `grant_generation INTEGER`, `seat_epoch INTEGER`, `grant_digest BLOB`, `grant_expiry_ms INTEGER`, `credential_digest BLOB`, `credential_expiry_ms INTEGER`, `revoked INTEGER` | One current seat lineage per side. A transfer uses a new authority ID. Renewal semantics are outside this package. |
| `probe_records` | `(campaign_id, sequence)` primary key; `prior_hash`, `record_hash`, `record_bytes BLOB`, `authority_id`, `seat_epoch`, `request_id` | Explicitly test-only opaque CAS probes. Not owner inputs, game events, receipts, or Chronicle records. |
| `probe_requests` | `(campaign_id, authority_id, request_id)` primary key; `input_hash`, `record_hash`, `sequence` | Durable exact-retry index for probes; not a public request lookup. |

Identifiers are exact lower-case ASCII: campaign ID 1–128 bytes from `[a-z0-9._-]`; authority/request IDs canonical lowercase UUID D form; side is `axis` or `commonwealth`. Hashes are lowercase `sha256:` plus 64 hex. Secrets are 32 random bytes encoded as lowercase 64 hex and stored only as SHA-256 digest of a domain tag, NUL, campaign ID, side, authority ID, generation and secret bytes. Fixed-time digest comparison is required. Probe record bytes are 1–65,536 bytes and never interpreted as P01 input. Over-cap, malformed ID/hash, changed-input retry and unknown version reject before any mutation.

## Transaction order

1. A host-only test adapter seeds an unissuable campaign binding. A real importer must later supply only a Core validated checkpoint and physically pinned ancestry; this package does not issue the adapter to a route. A new host activation increments `activation_fence` and rotates a 32-byte random lease secret in one immediate transaction. Every later mutation checks both the fence and a fixed-time digest of that secret in the same transaction. A stale process cannot reuse a newly readable numeric fence.
2. An operator-secret-authenticated grant issue stores one grant digest and expiry under the current fence and returns the secret once. Redemption atomically consumes the grant digest and writes a new random replacement credential digest for the same stable authority ID. No old grant or prior credential remains usable. A host restart can authenticate the replacement credential from retained digest; an old cookie is not a credential.
3. Revocation and probe append each use one immediate SQLite transaction and compare campaign ID, activation fence and the same durable `seat_epoch`. Revocation first increments epoch and invalidates the credential; append first commits its probe and retry index, then revocation can advance. No process-local semaphore is authority.
4. Probe append compares expected sequence/head hash, increments sequence once, stores exact bytes and `(campaignId, authorityId, requestId)` in the same transaction. An exact retry reads back and verifies bytes/hash before returning the stored sequence; altered reuse conflicts. After ambiguous commit, callers read back the exact request and record. Failed readback is unavailable, never inferred success. A stale activation fence cannot append.

The store must be tested after a new process instance opens the same file, including credential replacement, revocation, lost-response reconciliation, competing append/revoke order, stale fence and malformed/over-cap inputs. These tests prove storage primitives only. A future A2 binding/opening/input must use separate frozen schemas and Core replay and must pass the full AC-003/006/007/008 certificate before native/public admission.
