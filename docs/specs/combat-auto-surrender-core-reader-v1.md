# Private Core reader for the frozen automatic-surrender source

**Status:** unissuable source-reading slice. The exact Content8, Rules source and Setup8 bytes come from the [owner-approved source contract](combat-auto-surrender-source-v1.md). This reader does not create a campaign, issue or authenticate an R03 predecessor ledger, decide a surrender, or admit a P01 action.

`CampaignCombatAutoSurrenderSourceV1.Read` accepts three caller-supplied byte sequences only when each has the frozen byte count and SHA-256 from the source contract. It parses those exact JSON bytes and checks the selected one-orientation identity and Setup bindings: Axis attacker Ammo 10, Commonwealth defender Ammo 0, Cohesion 0, no *initial* external Ammo source, selected Close Assault scope and unsupported settlement. The returned internal value contains only frozen hashes, participant IDs and initial ammunition. It has no `CampaignCombatCreationContext` conversion, issuance method, receipt or ledger type. Content7 and Setup7 readers remain unchanged and reject the new source as before.

These pinned bytes prove a synthetic **initial source**, not that the defender still lacks accessible ammunition at an actual assault. A future versioned Content8/Setup8 creation contract must independently retain its canonical source, Rules/config selection, creation binding, actor, slot and clock. Eleven predecessor ledgers then need issuance and fresh readback with receipts and later ammunition-access evidence. Reusing or mutating the original 300 Content7 R03 roots would not satisfy that requirement. Until those artifacts exist, the automatic-surrender branch remains unsupported and zero actions are admitted or public.

Focused Core tests read the three retained fixtures and reject a byte mutation in each, alternate byte spelling, and original Content7 substitution. The existing [source oracle](verify-combat-auto-surrender-source-v1.py) retains the deeper field/origin and negative-vector checks; this Core reader intentionally accepts only its one pinned source triplet.
