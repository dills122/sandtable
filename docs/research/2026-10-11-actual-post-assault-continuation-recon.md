## Inferences and design consequences

I1. Smallest genuine successor needs four accepted publications, not an automatic Release shortcut: open34, complete35, control open36, repeat/finish37. It can cover genuine repeat and finish without completing future Movement. The four ordinary roots all have progress and a witness; no-progress/no-witness branches are isolated policy tests, not extra reachable actual roots.

I2. Own actual admission and assessment are unavoidable. Reusing Release internal transition after deriving/proving exact base is safe in principle because it does not invoke old `validate_base`; existing actual-positive contract already demonstrates reuse of internal kernels after new admission [S4]. New code must compare actual membership/history/configuration/World/position itself. Do not patch global Context, reseed request, replace creation binding, or normalize actual progress tag into historical event lineage.

I3. Implement own pure assessor on authenticated facts, reusing `mov.affected`, `mov.cost`, `mov.terrain_cost` and original-proof/geometry helpers where their primitives match. Old `ctl.assess` cannot serve directly. Own assessment retains actual paid receipt/hash; own transition follows SCC policy but new domains/source binding. No old `source`, `base_for`, SCT/SCC `read_base`, INITIAL reconstruction, Result1 promotion, or synthetic Movement descriptor participates.

I4. One source family can contain canonical PaidSource string and ordered continuation event strings; API receives four independent ledgers (selection/round/paid/continuation). Derive base/proof rather than accept them. A closed suffix effect union distinguishes Release open/completion and control open/repeat/finish. Optionally embed unchanged inner ReleaseEvent1 canonical bytes after actual-base validation, but new outer receipts must not masquerade as an extra authority turn. Decide framing before RED/literals. New source/base/event/control/receipt/manifest domains bind actual predecessor and external map.

I5. Current APA carrier ceilings cannot be copied blindly: successor nesting escapes a4MiB source and may embed a2MiB proof. Prefer one embedded PaidSource plus derived proof without duplicating source/proof at every suffix stage. Measure raw ASCII bytes, nesting/depth and worst-case retained collections; preserve inherited limits separately. Fixed four-event suffix caps own replay; repeated ordinal2 terminal cannot be fed back into this ordinal1 contract to loop indefinitely.
