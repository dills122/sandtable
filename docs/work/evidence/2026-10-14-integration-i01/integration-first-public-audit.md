## Executive decision

The fastest safe integration step is a **bounded ingress/result-support experiment followed by one additive actual-lineage public projection/submission boundary**, using accepted native families as authority and a separately retained trusted actor/clock ledger. Prepare independent public privacy/retry/occurrence vectors while the private owner performs that experiment; freeze shared interfaces before test or product writers consume them. Keep fresh public admission disabled until initial certification proves the entire admitted result/continuation surface. This reduces integration uncertainty without promoting seed-1 diagnostic lineage to a production gameplay profile.

A complete public loop is not a registration-only change. Public Core currently routes only Snapshot11/Content6. Exercise and Runner have additional independent assumptions that reject simultaneous assignment, cannot distinguish Movement1/Movement2, derive an incompatible seed, and use legacy receipt/schema identities. Existing strict replay/publication infrastructure is valuable, but these semantic joins need versioned contracts.

**The critical gate is initial profile certification, not repeat implementation alone.** The accepted actual root has two exact fixture opening hashes, fixed seed1 and idle initial Movement. Actual paid assault independently certifies all selected result handlers, but the PAC/RMV continuation ingress admits only the resulting Contact/no-custody world. A public capability must not use this fixed result to omit capture, Engaged, retreat or future-obligation continuation support. POL-001 explicitly prohibits filtering by seed or dropping capture; POL-008 prohibits seed-derived legality. Retaining isolated all-result arithmetic/handler tests is necessary but does not itself prove all-result public and continuation admission.

Recommendation for the 90-minute decision: grant the bounded experiment below, then choose an integrated dormant actual mapping or exact ingress prerequisite based on its measured result. Do not commit a broad fresh composer/schema system before the retention choice is proved necessary. Condition any public activation on the root/profile and post-result certification gates. A12-hour promise of complete Tasks020–025 is not supported by this audit. A narrowly labelled authentic demonstrator may be achievable sooner, but it is distinct from registered selected-profile gameplay and full Combat/skeleton acceptance.

The smallest now-supported candidate is an additive **Reaction closure → strict Movement completion → Breakdown → certified positive-entry source bridge**, using existing authenticated CP4 out-and-back history for both owners.
