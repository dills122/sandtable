# R02 engineering explanation (local implementation in progress)

This additive family closes only the authentic repeated Movement lifecycle. R01 still authenticates the original request and nine retained ledgers and determines the published ordinal-2 World/track/progress. R02 wraps that Source and adds a tenth ledger. It never accepts a fixture Control, a hash-only ancestor, or a source replayed with missing inputs. Each row independently reconstructs its complete ancestry; compact root/cut references compress test data, not adjudication work.

The smallest coherent lifecycle has one owner completion for zero real moves and three commands otherwise. Positive prefixes stop their exact real track and last move, resolve a mandatory empty cohort as System, and complete as the owner. The generic stop lives in interruptPositions in the canonical private-v5 catalog; ordinary successor positions live in positions. Capturing/restoring the full suspended position and full active authority preserves the canonical context rather than reducing it to a position ID.

Old originalMovementEnd remains ordinal 1. New movementEnd is ordinal 2 and uses the committed own completion receipt. The event is constructed from a receipt-free preview; the final proof is derived after the event receipt exists. Historical exclusions are retained and unioned with old/current proximity-derived exclusions. The World and all resource/progress/history/asset/duty fields remain exactly parent state. Reaching canonical Breakdown determination closes this fragment, not active cycle 2; prior closure still proves only the already-repeated first cycle.

Ownership precedes dependency callbacks. An Apply must use its owned request/ledger snapshot again for post-append verification. A real regression against the retained pre-fix oracle mutates the original prefix and movement list after initial capture: the old Apply rereads those original arguments and fails trusted-input; the corrected Apply succeeds for both profiles. Native validation must preserve this behavior test and byte-array/readback ownership assertions, not merely simulate a callback that never mutates original caller state.

The capacity proof distinguishes immutable reachable origins and full catalog positions from much larger arbitrary grammar-valid framing vectors. R01's five-move/new-DP World bound is inherited unchanged. R02 charges a second end proof and all own receipt copies, full stop and interrupt context, but never embeds a duplicate parent World/Proof. See the capacity derivation and arithmetic companion for component maxima; hard-cap fit alone is not closure evidence.

Reference TDD is staged at genuine authenticated ingress: missing lifecycle transition, then actual stop/missing System resolve, then actual resolve/missing completion, then complete lifecycle. One source lookup defect (searching only positions rather than interruptPositions) and one negative-vector defect (indexing a legitimately empty armed paid ledger) are retained as author failures, not semantic RED or passing evidence. Their corrected diagnostics and complete focused loops remain explicit in the final evidence.

The planned native test shape is 18 deterministic full-row classes and two support classes, each isolated in a fresh process. Primitive leading root/cut/profile display arguments avoid the historical long-string formatter collision. Discovery, process exit, exact row union, XML status and complete semantic work ownership are separate CI proofs. Fresh-process isolation does not assert same-process static/fixture concurrency safety. Native own-work and negative costs, installed MTP flags/discovery and final measured allocation remain pending; parent-only calibration establishes no R02 capacity guarantee.
