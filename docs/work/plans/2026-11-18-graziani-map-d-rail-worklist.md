# Map D pinned rail source worklist

**Date:** November 18, 2026. Reconciliation of the [42 pinned records](2026-11-18-graziani-map-d-pinned-rail-inventory.md), not a fresh map inspection. Classification concerns the **pinned rail feature on that exact side**. Source-positive includes qualified crossings, not approval of a route or a change to map data. Unknown means inspected but exact crossing or pinned finished/unfinished class remains unsettled. Not-yet-reviewed means no exact-side rail reading identified in the prior reviewed notes; it does not mean no ink. Open means the literal pin has no second endpoint, regardless of any nearby source observation. Categories partition the 42 records: **22 source-positive, 6 unknown, 12 not-yet-reviewed, 2 open**.

Pinned labels describe data, not scenario construction, damage, occupancy, usable rail, or an independently certified track. The map readings use the same [Map D scan and key](https://spigames.net/PDFv10/CNA_Maps.pdf), PDF pp. 4 and 1, SHA-256 `8830ec78df489607a2cc7e2cbc8ddcc9457ecbad3b11df071a60d825dadfd030`; informed rechecks are not independent editions. Pinned sides SHA-256 `124e6f943930f4fa718eb04fa1dc86b6089582aebfaff8fcb83f98ab30d98e6c`. Categories below and reproduction script use literal sorted pin keys; no geographic order or seam aliases are implied.

## Reproduce partition and inspect pin features

Run from repository root. Script checks the pinned-file hash, exact selection, explicit disjoint categories, and counts, then emits every row with its pin features. It verifies this worklist's transcription and arithmetic, not the visual interpretations in cited notes.

```sh
python3 - <<'PY'
import collections, hashlib, json, re
from pathlib import Path

path = Path('src/Cna.Core/Content/HistoricalMap/hexsides.v1.json')
raw = path.read_bytes()
assert hashlib.sha256(raw).hexdigest() == '124e6f943930f4fa718eb04fa1dc86b6089582aebfaff8fcb83f98ab30d98e6c'
is_d = lambda v: isinstance(v, str) and re.fullmatch(r'D\d{4}', v) is not None
rows = [r for r in json.loads(raw)['hexsides']
        if {'railroad', 'unfinished-railroad'} & set(r['features'])
        and any(is_d(r[f]) for f in ('a', 'b'))]
key = lambda r: r['a'] + '|' + (r['b'] if r['b'] is not None else r['side'])
by_key = {key(r): r for r in rows}
assert len(rows) == len(by_key) == 42
sets = {
    'source-positive': '''D3133|D3232 D3230|D3231 D3230|D3330 D3231|D3232
        D3322|D3323 D3322|D3421 D3323|D3324 D3324|D3325 D3325|D3326
        D3326|D3327 D3327|D3328 D3328|D3329 D3329|D3330 D3419|D3420
        D3419|D3519 D3420|D3421 D3515|D3615 D3517|D3518 D3518|D3519
        D3601|D3602 D3615|D3715 D3714|D3715'''.split(),
    'unknown': '''D3231|D3331 D3421|D3422 D3517|D3616 D3611|D3612
        D3612|D3613 D3615|D3616'''.split(),
    'not-yet-reviewed': '''D3514|D3515 D3514|D3613 D3602|D3603
        D3603|D3604 D3604|D3605 D3605|D3606 D3606|D3607 D3607|D3608
        D3608|D3609 D3609|D3710 D3611|D3711 D3710|D3711'''.split(),
    'open': 'D3133|E D3601|W'.split(),
}
counts = collections.Counter(k for group in sets.values() for k in group)
assert set(counts) == set(by_key) and all(n == 1 for n in counts.values())
assert {name: len(group) for name, group in sets.items()} == {
    'source-positive': 22, 'unknown': 6, 'not-yet-reviewed': 12, 'open': 2}
for name, group in sets.items():
    print(name, len(group))
    for k in sorted(group):
        r = by_key[k]
        assert (r['b'] is None) == (name == 'open')
        print(' ', k, ','.join(r['features']), 'up=' + str(r.get('up')))
PY
```
