## Exact authoritative handoff required before public activation
Existing components: trusted CampaignCombatCreationRequest/CreationContext, independently retained Created11 and canonical ancestral event bytes; strict private readers for actual positive selection/round/paid/PAC; PAC owned result plus world/random/version/prefix/members/movementEnd/attackHistory/targetUses/closure fields; existing initial-H fullroot compose/restore precedent.

Missing composition contract: an owned retained input/evidence envelope that separates authenticated admission metadata from embedded Source, routes each supported cut to its strict reader, exposes a typed projected authority state, and retains complete cumulative history plus independent ledgers across restart. Need exact reconstruction equivalence, immutable creation/config/content binding, original RNG, pending-window owner/audience, cycle occurrence and closure/future obligations. A public observation/action is derived from this authority only. Restore cannot fresh-create absent evidence or trust cached Control/Proof. Existing PAC Control receipts are suffix-only; do not treat them as complete campaign receipts or merge them by event-count heuristic. Existing private packed Source depth/size must not be shoehorned into 1MiB Initial-H Snapshot limits; composition schema/retention policy must explicitly choose evidence references or bounded stored bytes and authenticate them.

Public lane must define dual-seal owner/action bindings, side-safe projection, submission clock/authentication and pending recovery. Private handoff must provide deterministic System commands without exposing hidden state, and admit only the certified supported branch. Unsupported reachable results must block activation explicitly until implemented; they cannot become empty selection, finish, or successful Exercise terminal.
