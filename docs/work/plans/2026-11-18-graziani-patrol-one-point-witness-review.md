# Review: one-point patrol fixed-setup candidate

**Disposition:** Candidate and one-point qualification are supported conditionally; no actual legal patrol, target state or loss is established. One path-rule qualification should be made explicit in the [source note](2026-11-18-graziani-patrol-one-point-witness.md).

## Finding

Land §16.22 does **not** simply ban every enemy-controlled intermediate hex: its wording excepts a hex in the ZOC of the unit being reconnoitered. The note correctly asks for an exact path and enemy-ZOC check without claiming an automatic ban, but should name this exception so a future C3921 check does not discard a candidate solely because the C3920 target projects a qualifying ZOC there. A qualifying target ZOC, terrain passability, other enemy control or occupancy and interpretation of overlapping control still need independent evidence; the exception does not prove C3921 traversable. The [Halfaya edge analysis](2026-11-17-graziani-halfaya-edges-next.md) records the C3921/C3922 escarpment separately from C3920/C3921, and does not prove a full patrol route.
