## Errata, precedence and census result

The inspected September errata p. 2 §32.0 warns that abstract rules were untested; it is not a direct numerical correction. The numbered sequence on that page has no direct §32.41–.47 entry. Errata p. 3 §56.29 offers an alternative reordering of Axis Convoy Level Chart letters under its stated restrictions. Whether that optional detailed-chart variation applies to §32.44's abstract lookup is a separate mode and option decision; do not silently replace the checked base B values or assume the option is excluded. This is a bounded numbered-entry check, not proof that no indirect or later clarification exists.

All seven printed §32.4 cases are represented in LA-16's range; LA-11 covers initial setup, LA-15 movement, and LA-18 convoy details. Existing reviews cover the printed cases and the selected 1940 table cells, with known scenario-start and placement ambiguities. No wholly unreviewed **numbered case** was identified in this comparison; that does not certify all table cells, all related rules, every arrival category, current queue completeness or runtime behavior. A meaningful next source check should name an actual scenario exception, chart option, startup record or receipt category rather than merely repeat the reviewed case text. Actual dates, die rolls, supply units, owner choices and successful delivery remain state facts.
