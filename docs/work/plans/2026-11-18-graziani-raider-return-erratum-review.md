# Raider return and SAS cross-reference: independent review

**Date:** November 18, 2026. Reviewed [raider return note](2026-11-18-graziani-raider-return-erratum.md) against [Land](https://www.spigames.net/PDFv10/CNA_LandGameRules.pdf) printed/PDF pp. 38 and 40, [September errata](https://www.spigames.net/db_pages/ERR_CampaignforNorthAfrica.pdf) PDF p. 2, [Commonwealth reinforcement schedule](https://spigames.net/PDFv10/CNA_ChartsCWPlayer.pdf) PDF p. 3, and [scenario](https://spigames.net/PDFv10/CNA_Scenarios_DupFromAirRules.pdf) PDF pp. 3–4. Same scans, independent reading; not independent edition.

- **Return:** Land §27.16 permits formation from the eliminated LRDG counter four Game-Turns later; example eliminates in OpStage 2 and forms in OpStage 3. Errata §27.16 directs returning LRDGs to §27.13 and changes old example labels to GT55 and GT59. The note correctly treats GT1 to GT5 as conditional arithmetic, not proof of initial eligibility, elimination, actual return, or universal return stage. Section 27.13 requires removal of a Recce/armored-car TOE point in the Organization Phase; §27.12 separately requires an existing unit that reached maximum morale through training. Do not infer return with no new qualifying point.
- **SAS:** Original §27.88's placeholder reference is corrected to §27.32, which states initial placement followed by secret location/movement recording and ordinary Recce-vehicle movement rules. Section 27.88 permits a 30 CP allowance and concealed LRDG-style movement on stacking and requires LRDG escort until SAS is placed back on the map. Minor precision: the reviewed note's sentence could be read as establishing an explicit end time for the *30 CP allowance*; printed case explicitly ties escort to map replacement but does not separately specify the allowance's duration. Avoid inferring a separate duration rule from this sentence. No altered route or waiver follows.
- **Schedule:** Commonwealth §4.43a lists SAS Brigade at GT47 OpStage 2. Scenario §60.22 ends GT6 OpStage 3; §60.47 directs use of the reinforcement track. Initial setup §60.41 does not list SAS. The note appropriately confines its conclusion to those sources and leaves other possible entry mechanisms unexamined.
