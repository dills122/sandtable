# Graziani Amiriya coordinate: bounded policy options

**Date:** November 18, 2026. **Disposition:** Planning recommendation only; no coordinate correction, runtime or data admission. Source conflict remains unresolved.

## Evidence and precedence

The [independent review](2026-11-18-graziani-amiriya-coordinate-conflict-review.md) verifies that §60.5's Graziani initial airfields table prints Amiriya **E2212**. The separate, later Desert Fox scenario §61.33 prints Amiriya **E3212** as an airfield. That is competing evidence, not an identified correction to Graziani: scenarios occur at different times and can have different setups. The reviewed 1979 errata contains no direct correction, within the search limits described in the review. Other editions or indirect corrections remain unchecked.

Map E has a circular mark inside E3212 near the Amiriya label; its identification as the named settlement point is uncertain because of nearby training-area artwork. Even if it is the settlement dot, it is not an identified airfield symbol and cannot alone locate an initial airfield. E2212's lack of an identified named dot or airfield symbol does not disprove the scenario table. Neither label overlap nor this evidence establishes E3312, an alias, or a map-based correction.

For this decision, rank an explicit applicable correction, if found and verified, above the applicable scenario setup; use that scenario's printed row before a separate scenario or an ambiguous map mark. This is a proposed project precedence rule, not a claim that the sources establish such a hierarchy. Preserve each source's own statement and provenance regardless of selected interpretation.

**Recommendation:** A is the defensible default for a future source-faithful Graziani interpretation, subject to explicit adoption and versioning. It follows the applicable scenario row without calling the conflict settled. If the project cannot accept that default pending source or policy review, use C. Do not select B as an asserted erratum on this evidence. A verified applicable correction would require revisiting this recommendation, not silently rewriting existing records or replays.
