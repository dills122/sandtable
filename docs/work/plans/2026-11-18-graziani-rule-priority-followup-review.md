# Review: rain-wadi breakdown chart cross-check

**Disposition:** Source reading and conditional distinction supported. No source priority or universal rain breakdown value established. No material correction found.

- Visually checked §8.37 in Air PDF p. 23. The road breakdown cell is ½ with note 6; note 6 negates hexside terrain-feature entry costs and breakdown values. The wadi row separately gives +8 BP. The track cell points to note 8, which halves terrain-feature entry costs and hex/hexside breakdown values except the stated vehicle down-escarpment costs. Note 10 restricts rain-wadi crossing to a road or railroad, treats railroad as road for that purpose, and adds 2 CP; it does not supply a breakdown total. This railroad detail has already been recorded in prior review.
- Land §8.41, pp. 14–15, distinguishes normal road breakdown (½ BP) from track wadi crossing (4 BP rather than 8); its rain-road sentence says +2 CP with no additional breakdown, “still ½ BP.” That explicit ½ is a stated rate, not merely a statement that the wadi increment is zero. It need not be read as resolving how unrelated features or an entire multistep move are totaled.
- Land §29.56, p. 41, gives all road hexes the same movement cost and breakdown rate as tracks during rain; §21.37(c), p. 34, likewise treats road breakdown values as track values. The chart's separation supports analyzing the wadi contribution separately from the hex rate, but does not prove that note 6's road negation remains applicable when the rain road is treated as track for a particular purpose. If that negation is retained, removing the wadi increment still does not by itself select the underlying road-versus-track hex rate. If track treatment includes the hexside, note 8 and §8.41's track discussion require separate reconciliation. Neither construction settles precedence against §8.41's explicit rain ½.
- For illustration only, the chart gives clear terrain a breakdown value 4; a track's note 8 halving would make that base contribution 2, before any separately applicable hexside or feature effects. This does not prove 2 or 6 is the rain-road crossing cost, which rule wins, eligibility for breakdown, or legality of a particular crossing. Land §32.55's Motorization Point exemption remains separate.
