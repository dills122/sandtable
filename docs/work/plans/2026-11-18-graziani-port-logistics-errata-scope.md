# Logistics errata §§54.17, 55.11 and 55.3: Land-only scope

**Finding:** §54.17 corrects the detailed supply-dump demolition table, not rail use. Land §32.17 separately specifies abstract Supply Unit destruction. Corrected Land §30.59 points to the §55.3 port chart for personnel handling; §32.36 separately retains a destination-efficiency condition for Commonwealth abstract Supply Units. Neither reference automatically imports the chart's entire detailed shipping system or the errata's conditional Axis G/Tripoli excess-tonnage exception.
