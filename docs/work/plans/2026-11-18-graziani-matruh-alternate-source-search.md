# Matruh: bounded alternate-source search

**Date:** November 18, 2026. Public web search for a later publisher clarification or independently identifiable source bearing on Matruh's Land-only Supply Unit placement, stacking or abstract-air payment. Scope excludes the separate CCNN search. No rights holder was contacted; no external scan, map, counter art or text was added to the repository. **Result:** no authoritative later Matruh-specific correction found in this bounded search. This is not proof that none exists.

Results from other games with similar titles were not treated as evidence. Search-engine indexing, community documents, access conditions and edition provenance limit completeness; separately identified physical printings, archived publisher correspondence or unindexed periodicals could change the result.
