The Map D image embedded in the existing PDF is a **10,585 × 6,689 JPEG at 300 ppi** (`pdfimages -f 4 -l 4 -list`); rendering at 600 or 800 dpi interpolates that same image and does not create source detail. The earlier 200-dpi views for D3612 and batch A sampled below the embedded resolution, so a targeted native-resolution or enlarged rendering is a concrete, bounded next check for class, particularly where neighboring segments escape overprint. Batch C's 600-dpi rendering exposed interruptions missed in a 200-dpi crop, but does not establish that the same technique will settle these ten. For the already enlarged junction reviews, merely increasing output dpi is less promising than a cleaner independently captured source. A separately sourced print or scan needs provenance, edition and registration checked; VASSAL-derived pin labels are a comparison claim, not independent visual proof of their own source.
